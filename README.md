# TO-DO API 
## Descripción
Este proyecto consiste en una **API REST sencilla para la gestión de tareas**.
El objetivo principal de este proyecto no es la complejidad funcional, sino demostrar lo que incluye un desarrollo profesional completo de software** incluyendo:
- API First
- Aplicar Test-Driven Development (TDD)
- Agile Testing (Q1-Q4)
- Gestión de código con GitHub

Este proyecto forma parte de la práctica **Implementación de un Pipeline de Entrega Continua y Calidad Automatizada** de la asignatura **Desarrollo del software -- Curso 2025-2026**.
